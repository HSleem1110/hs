# 러시아어 문법 퀴즈 — 오프라인 파일

`russian-quiz.html` 하나만 있으면 인터넷 없이 브라우저에서 문제를 풀 수 있어요.
문제, 채점, 원어민 녹음 677개, 키릴 문자 글꼴(PT Serif)이 모두 파일 안에 들어 있어요.

## 쓰는 법

1. `russian-quiz.html`을 내려받아 원하는 폴더에 둡니다.
2. 더블클릭해서 Chrome · Edge · Safari 같은 브라우저로 엽니다.
3. 인터넷이 없어도 모든 메뉴를 풀 수 있어요. 기록은 그 브라우저에 저장돼요.

## 업데이트

- 인터넷에 연결된 상태로 열면 이 저장소의 `version.json`을 확인해요. 새 버전이 있으면 홈 화면 위쪽에 알림이 나와요.
- **업데이트**를 누르면 새 버전을 받아 브라우저에 저장하고 다시 열어요. 다음부터는 오프라인에서도 새 버전으로 열려요.
- 브라우저가 저장을 막으면 '정보 → 최신 파일로 저장'으로 새 파일을 받아 기존 파일과 바꿔 쓰면 돼요.
- 새 버전은 Claude에게 수정을 부탁하면 이 폴더에 올라와요.

## 기록 옮기기

Claude 앱 안의 퀴즈와 이 파일은 기록을 따로 저장해요. 옮기려면 '오답 노트 → 백업 파일 받기'로 받은 파일을 다른 쪽에서 '백업 불러오기'로 불러오세요.
두 기록은 합쳐져요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `russian-quiz.html` | 오프라인 실행 파일 (아래 세 파일 + 글꼴을 하나로 묶은 것) |
| `app.js`, `app.css` | 앱 본체. 업데이트할 때 이 두 파일을 받아요 |
| `version.json` | 현재 버전 번호와 바뀐 점 |
| `tools/make_file.py` | `app.js` · `app.css` · `version.json`으로 `russian-quiz.html`을 다시 만드는 스크립트 |

## 패치 올리는 법 (Claude용)

1. `app.js` 또는 `app.css`를 고칩니다.
2. `version.json`의 `ver`를 올리고(예: `2026.10.22.1` → `2026.10.22.2`) `notes`에 바뀐 점을 적습니다.
3. `python3 ruquiz/tools/make_file.py`로 `russian-quiz.html`을 다시 만들고 함께 커밋합니다.
