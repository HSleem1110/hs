# 프랑스어 문법 퀴즈 만들기 — 새 Claude 대화에 붙여 넣는 프롬프트

아래 줄부터 끝까지 복사해서, 이 저장소(HSleem1110/hs)가 연결된 새 Claude Code 대화에 붙여 넣으세요.

---

이 저장소의 `ruquiz/`는 내가 쓰는 러시아어 문법 퀴즈 앱이야. 먼저 `CLAUDE.md`, `ruquiz/README.md`, `ruquiz/app.js`, `ruquiz/tools/`를 읽고 구조를 파악해 줘. 이 앱을 바탕으로 **프랑스어 문법 퀴즈(`frquiz/`)**를 만들어 줘. 러시아어 앱의 틀(화면 · 기록 · 오답 노트 · 오프라인 파일 · 자동 업데이트 · 발음 도구)은 그대로 가져오되, 내용과 배치는 **한국어를 쓰는 학습자가 프랑스어를 가장 효율적으로 익히는 방식**으로 다시 설계해 줘. 러시아어 전용 요소(격 변화, 강세 표시, 출몰모음, 키릴 글꼴)는 버리고, 프랑스어에서 정말 어려운 지점에 집중해.

## 0. 시작 전에 나에게 물어볼 것 (짧게, 한 번에)
- 지금 내 수준(완전 처음 / A1 / A2 / B1 이상)과 쓰는 교재가 있는지. 교재가 있으면 사진을 받아 초급 범위를 교재 그대로 맞춰.
- 프랑스 프랑스어 기준으로 할지(기본), 캐나다 프랑스어도 필요한지.
나머지는 아래 기본값대로 진행하고, 결정할 때마다 이유를 한 줄로 알려 줘.

## 1. 그대로 가져올 것 (러시아어 앱과 같은 방식)
- 한국어 화면, 홈 · 메뉴별 설정 · 퀴즈 · 결과 · 오답 노트 · 정보 구성, 하단 탭(학습 · 오답 노트 · 정보), 이어서 하기, 난이도(초급 · 중급 · 고급 · 통합), 객관식 / 주관식, 정답 아래 문법 태그(예: `la · 정관사 · 여성 단수`), 예외 배지, 키보드 단축키(1–4, Enter, Esc), 그만하기 확인 창.
- 기록: claude.ai 아티팩트에서는 Claude 계정(db 기능), 오프라인 파일에서는 브라우저 저장. 백업 파일로 서로 합치기. 오답 노트는 틀린 횟수 ≥ 맞힌 횟수인 문제.
- **오프라인 단일 파일** `frquiz/french-quiz.html` + **자동 업데이트**: 앱 코드(`app.js` · `app.css`)와 소리 팩(`audio-native.json`, `audio-tts.json`)을 나누고, 인터넷이 연결되면 `version.json`을 보고 바뀐 부분만 스스로 받아 다음 실행 때 적용. 버튼을 누를 필요가 없어야 해. 러시아어 앱의 `tools/make_file.py` 구조를 그대로 써.
- **저장 공간을 러시아어 앱과 반드시 분리해.** 두 파일을 같은 컴퓨터에서 `file://`로 열면 저장 공간을 같이 써. 그래서 IndexedDB 이름(`frquiz-app`), localStorage 키(`frQuizRec1`, `frQuizUI1` 등), 업데이트 주소(`frquiz/` 경로)가 모두 러시아어 앱과 달라야 해.
- 새 claude.ai 아티팩트로 게시하고, 그 주소를 `CLAUDE.md`에 프랑스어 앱 항목으로 적어 둬.
- `CLAUDE.md`에 프랑스어 앱 규칙(아래 4·5절 포함)을 러시아어 앱처럼 정리해서, 다음 대화의 Claude도 같은 방식으로 작업하게 해.

## 2. 메뉴 배치 (프랑스어에 맞게 새로)
한국어 화자가 가장 많이 틀리는 순서로 배치해. 각 메뉴의 ‘알아 두기’에는 규칙을 짧은 표로 넣어.

**어휘**
1. **단어** — 뜻 맞히기(한 단어 / 문장 속 두 단어). 명사는 **항상 관사와 함께** 보여 주고 외우게 해(`la table`, `le livre`). 성은 색과 기호를 함께 써서 표시해(색만 쓰지 말 것).
2. **숫자 · 시간** — 특히 70–99(soixante-dix, quatre-vingts, quatre-vingt-dix), 서수, 날짜 · 시각 읽기. 듣고 숫자 쓰기 모드 포함.

**명사 · 관사 · 형용사**
3. **관사와 성** — 정관사 · 부정관사 · **부분관사**(du, de la, des), 축약(au, aux, du, des), 엘리지옹(l', d'), 부정문의 `pas de`. 성 추측 규칙(-tion · -té → 여성, -ment · -age → 남성 등)과 예외.
4. **복수형** — -s / -x, -al → -aux, -eau → -eaux, 불규칙(œil → yeux), 발음은 안 바뀌는 경우가 대부분이라는 점.
5. **형용사** — 성 · 수 일치(beau → bel → belle, nouveau, vieux 포함), **위치**(BANGS: 아름다움 · 나이 · 숫자 · 좋고 나쁨 · 크기는 명사 앞), 뜻이 바뀌는 위치(un grand homme / un homme grand), 소유형용사(mon · ma · mes, 모음 앞 여성 mon), 지시형용사(ce · cet · cette · ces).

**동사** (가장 비중 크게)
6. **현재형** — -er · -ir(finir형) · -re · 필수 불규칙(être, avoir, aller, faire, pouvoir, vouloir, devoir, savoir, prendre, venir, mettre, dire, voir). 철자는 다르지만 소리가 같은 형태(parle · parles · parlent)를 듣기 문제로.
7. **복합과거** — avoir / être 고르기(être를 쓰는 동사 목록 · 대명동사), 과거분사(불규칙 포함), **과거분사 일치**(être 동사, 앞에 온 직접목적어).
8. **반과거 vs 복합과거** — 문장 속에서 고르기.
9. **미래 · 조건 · 접속법** — 근접미래(aller + 동사원형), 단순미래, 조건법(고급), 접속법(고급, il faut que · vouloir que 뒤).
10. **대명동사** — se lever 변화, 복합과거에서 être + 일치.

**대명사 · 문장**
11. **대명사** — 직접 · 간접목적보어(le · la · les / lui · leur), **y와 en**, 강세형(moi, toi…), **대명사 순서**(me le, le lui …), 관계대명사(qui, que, où, dont).
12. **부정문 · 의문문** — ne … pas / plus / jamais / rien / personne, 의문 3가지(억양 · est-ce que · 도치), 의문사.
13. **전치사** — 도시 · 나라 · 대륙 앞 à / en / au / aux(나라의 성에 따라), 교통수단(en / à), 시간 전치사.

**발음 (프랑스어 전용 메뉴, 꼭 넣어)**
14. **발음** — 듣기 중심 연습:
    - 안 읽는 글자: 끝 자음(CaReFuL 예외), 3인칭 복수 -ent, h muet / h aspiré.
    - **리에종**: 필수 · 금지 · 선택. 구(句)를 보고 ‘이어 읽나?’ 고르기, 듣고 고르기.
    - 엘리지옹 · 앙셴망.
    - 비모음(an / en, in / un, on) 구별.
    - 숫자 발음 변화(six, dix, huit, cinq가 뒤 단어에 따라 달라지는 것).
    - plus [ply] / [plys], fils, os처럼 같은 철자를 다르게 읽는 단어.
15. **받아쓰기(dictée)** — 문장을 듣고 입력하기. 프랑스어에 가장 효과가 큰 연습이라 꼭 넣어.

**실전**
16. **종합 시험** — 모든 메뉴를 섞고, 한 문장 안에서 관사 · 형용사 일치 · 동사 시제 · 대명사를 함께 맞히는 종합 문제 포함.

정답 아래 문법 태그는 프랑스어에 맞게 바꿔(예: `belle · 형용사 · 여성 단수 · 명사 앞`, `est allée · 복합과거 · être · 여성 일치`, `les‿amis · 리에종 필수`).

## 3. 프랑스어 화면 표시
- 강세 표시 대신, 원하면 켜고 끌 수 있는 **IPA 발음 기호**와 **리에종 표시(‿)**, **안 읽는 글자를 연하게** 보여 주는 표시를 넣어.
- 주관식 입력: 화면에 악상 버튼(é è ê à â ç ù û î ï ô œ æ)을 두고, 채점에서는 악상이 틀리면 ‘거의 맞음(악상 확인)’으로 따로 알려 줘(기본은 오답 처리하되, 설정에서 너그럽게 채점하기를 고를 수 있게).
- 글꼴은 프랑스어 악상이 깔끔한 것으로 고르고, 오프라인 파일에 넣어.

## 4. 발음 소리 (가장 정확한 쪽으로)
**원어민 녹음** (`fetch_audio.py`를 프랑스어용으로)
- 출처: 위키미디어 공용의 Lingua Libre 프랑스어 녹음(`LL-Q150 (fra)-…`)과 위키낱말사전 `Fr-…` 녹음. 프랑스어는 Lingua Libre에서 가장 많이 녹음된 언어라 단어 녹음 대부분을 원어민으로 채울 수 있을 거야.
- 찾기: kaikki.org의 영어판 위키낱말사전 프랑스어 추출본과 프랑스어판(`fr-extract`) 추출본을 써. 위키미디어 API는 속도 제한이 심하니 쓰지 마.
- 받기: 미러(ftpmirror.your.org)를 먼저 쓰고, 공용 원본 서버는 429면 이번 실행은 멈추고 다음에 `--retry`.
- **동형이의어 확인**: 러시아어 앱은 강세로 확인했지만, 프랑스어는 **IPA와 품사**로 확인해(est [ɛ] vs [ɛst], fils, plus, président 명사 vs présidENT 동사). 녹음이 달린 사전 항목의 IPA가 앱이 기대하는 IPA와 같을 때만 넣어.

**음성 합성** (`make_tts.py`를 프랑스어용으로)
- 후보를 비교해서 내가 귀로 고르게 해 줘. 오프라인에서 돌릴 수 있고 개인 비영리로 쓸 수 있는 것만:
  1. **Piper** 프랑스어 목소리(fr_FR-siwis, fr_FR-upmc, fr_FR-tom 등). 목소리마다 모델 카드의 라이선스를 확인해.
  2. **Kokoro**(Apache-2.0) 프랑스어 목소리.
  3. **XTTS-v2**(Coqui, 비영리 라이선스). 품질은 높지만 무거워.
  4. 그 밖에 비교할 만한 프랑스어 모델이 있으면 함께.
- 비교용 시험 문장 세트를 만들어 각 모델로 생성해서 보내 줘. 리에종(les amis, ils ont), 금지 리에종(les héros, et‿ 없음), 비모음, 숫자(six élèves / six garçons / il en a six, quatre-vingt-dix), 안 읽는 -ent, plus, fils, 엘리지옹을 꼭 넣어. 내가 고른 모델과 목소리로 전부 만들어.
- **프랑스어 발음은 단어 사이에서 바뀌어서(리에종), 단어만이 아니라 구와 문장도 미리 만들어.** 관사 + 명사(`les‿enfants`), 형용사 + 명사, 주어 + 동사(`ils‿ont`, `nous‿avons`), 예문, 받아쓰기 문장까지 넣어. 미리 만들 수 없는 조합만 기기 음성으로 읽어.
- 러시아어 앱의 `phon()`처럼, 합성이 틀리게 읽는 예외(h aspiré, 숫자 변화, 고유명사, 외래어, 드물게 읽는 끝 자음 등)를 하나하나 확인해서 합성할 때만 고쳐 적는 규칙을 만들어. 규칙이 바뀌면 그 단어만 다시 만들어지게 해(`tts-text.json`).
- 설정에서 원어민 녹음 / 음성 합성 중 먼저 들을 쪽을 고르게 하고, 버튼 색으로 구분해(파랑 = 원어민, 초록 = 합성, 회색 = 기기 음성).
- 네이버 사전처럼 약관상 수집이 금지된 곳의 음원은 넣지 말고 링크로만 연결해. 저장소가 공개라 넣으면 배포가 돼.
- 외부 서버에서 소리를 불러오지 마. 모든 소리는 파일 안에 넣어서 오프라인에서도 재생돼야 해.
- **단어를 추가하거나 바꾸면 원어민 녹음과 음성 합성을 반드시 자동으로 같이 만들어.**

## 5. 사전 링크
정답 확인 뒤 네이버 프랑스어사전 · Wiktionnaire · Larousse · WordReference · Forvo 링크를 보여 줘.

## 6. 진행 방식
1. 0절 질문 → 메뉴 배치와 데이터 출처를 짧게 확정.
2. 음성 합성 후보 비교 샘플을 먼저 보내서 모델을 고르게 해(나는 귀로 판단하고, 너는 들을 수 없으니 추측으로 정하지 마).
3. 초급 범위로 앱을 먼저 만들어 아티팩트로 올리고, 내가 써 보며 고칠 수 있게 해.
4. 그다음 중급 · 고급, 원어민 녹음, 오프라인 파일, 자동 업데이트를 붙여.
5. 단계마다 실제 브라우저로 동작을 확인하고(오프라인 · 업데이트 포함), 확인한 것과 못 한 것을 구분해서 알려 줘.
6. 커밋은 지금 작업 브랜치에 하고 푸시해. 오프라인 파일의 업데이트 주소가 그 브랜치를 가리키니, 브랜치를 바꾸면 미리 알려 줘.
